# Labb_3_QuizApp

## Om projektet

QuizApp är en frågesportsapplikation utvecklad i C# med WPF. Användaren får svara på flervalsfrågor och får direkt återkoppling på om svaret är rätt eller fel.

## Viktiga tekniska lösningar:

Applikationen använder sig av MVVM-mönster för att separera grafiskt gränssnitt från logiken samt RelayCommands för hantering av knapptryck och navigering genom Commands istället för att logiken ligger i code-behind.
Annan viktig teknik är Databinding för att koppla ihop projektet.
